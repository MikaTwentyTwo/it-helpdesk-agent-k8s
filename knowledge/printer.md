# Printer troubleshooting
Ask for the printer model, connection type and exact error message.
Check power, paper and displayed errors.
Check that the intended printer is selected and inspect the print queue using the user's OS interface.
Restore the user's network connectivity before diagnosing a network print job.
Suggest a built-in test page only according to the printer manual or known OS procedure.
Do not invent a universal application named Print or unspecified interface buttons.
Do not assume USB fallback is supported or permitted.
Do not assume that the printer and computer must have equal IP addresses.
Driver installation and network changes must follow corporate IT policy.
